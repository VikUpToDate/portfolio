How I Check AI-Generated Code

  1. Understand the task. What should it do? I define the problem and what I expect the code to do.
  2. Understand the code. How does it work? I follow the steps until I can explain how the code gets its result.
  3. Understand the result. Does it match? I test the change against what I expected and compare timings if speed was the goal.
